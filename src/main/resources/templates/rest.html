A sütemények kezeléséhez RESTful API áll rendelkezésre JSON formátumban. Az adatok olvasása bárki számára elérhető, a létrehozás, módosítás és törlés csak admin felhasználóval (HTTP Basic azonosítás) lehetséges.

Végpontok

MetódusURLLeírásJogosultság
GET/api/sutikÖsszes sütemény listázásabárki
GET/api/sutik/{id}Egy sütemény lekérése (404, ha nincs ilyen)bárki
POST/api/sutikÚj sütemény létrehozása (201 Created)admin
PUT/api/sutik/{id}Sütemény módosításaadmin
DELETE/api/sutik/{id}Sütemény törlése (204 No Content)admin

Kipróbálás a böngészőben

Kattints a gombra a válasz megtekintéséhez.

cURL példák

Az admin felhasználónevét és jelszavát cseréld a sajátodra. Windows PowerShellben a curl helyett curl.exe kell, és a JSON idézőjeleit \" formában kell megadni.

Összes sütemény

curl http://localhost:8080/api/sutik

Egy sütemény

curl http://localhost:8080/api/sutik/1

Új sütemény létrehozása

curl -u admin:JELSZO -X POST http://localhost:8080/api/sutik \
  -H "Content-Type: application/json" \
  -d '{"nev": "Teszt torta", "tipus": "torta", "dijazott": false}'

Módosítás

curl -u admin:JELSZO -X PUT http://localhost:8080/api/sutik/140 \
  -H "Content-Type: application/json" \
  -d '{"nev": "Teszt torta (módosítva)", "tipus": "torta", "dijazott": true}'

Törlés

curl -u admin:JELSZO -X DELETE http://localhost:8080/api/sutik/140
